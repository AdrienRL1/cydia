If Cydia refuses this HTTPS source ("could not be verified" / TLS error), your device is missing the modern http, not https (the device can't yet verify the very certificate it's about to install).

  • On the device, open http://repo.invoxiplaygames.uk/certificates/ in Safari — use AppSync Unified — needed to install unsigned IPAs (auto-installed as a dependency)
  • Tap ISRG Root X1 CA (Let's Encrypt) and install it (Settings > General > Profiles if it doesn't open on its own).
  • Return to Cydia and add https://adrienrl1.github.io/cydia/ again — it now validates.

iOS 6 and newer already trust this root (tested on iOS 6.1.3 / 6.1.4), so this is only needed on the earliest devices. Certificate page courtesy of InvoxiPlayGames.
